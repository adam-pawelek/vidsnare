    Installing

    1. wget https://github.com/adam-pawelek/vidsnare/releases/latest/download/VidSnare_amd64.deb
    2. sudo apt install ./VidSnare_amd64.deb
    3. vidsnare

    sudo apt remove vidsnare
    1. wget https://github.com/adam-pawelek/vidsnare/releases/latest/download/VidSnare-x86_64.AppImage
    2. chmod +x VidSnare-x86_64.AppImage
./VidSnare-x86_64.AppImage

    If it doesn’t start

    # Ubuntu 24.04 and newer
sudo apt install libfuse2t64
# Ubuntu 22.04, Debian
sudo apt install libfuse2
# Fedora
sudo dnf install fuse-libs
# Arch, Manjaro
sudo pacman -S fuse2
